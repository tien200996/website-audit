# website-audit

Audit websites against your own rules.

## Getting started

1. Copy the [example](example) folder, a starter library of rules you can change.
2. In the copy, run:
   ```sh
   npm i
   ```
3. Open Claude Code in the copy and run:
   ```
   /mcp__website_audit__client_audit {clientName}
   ```
