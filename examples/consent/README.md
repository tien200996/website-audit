# Consent audit

Checks if a website asks for cookie consent before tracking, and if Google tags follow that choice.

Built with [website-audit](https://www.npmjs.com/package/website-audit).

## Getting started

1. Run `npm i`.
2. Open Claude Code here and run `/mcp__website_audit__client_audit {clientName}`.

Run it from the country you audit, the banner can differ by country.

Run `/mcp__website_audit__library_builder` to write your own rules.
